Гусиный Магазин Приложений
Что это
Это центральный репозиторий приложений для Гусиной Империи. Отсюда граждане скачивают приложения и устанавливают их через Гусиное Ядро.

Структура репозитория
index.html - страница-каталог со списком приложений

info.json - метаданные всех приложений

apps/ - папка с ZIP-архивами приложений

Формат info.json
{
"имя-приложения": {
"name": "Отображаемое имя",
"desc": "Краткое описание (до 100 символов)",
"version": "1.0.0",
"author": "Имя автора",
"icon": "🦆",
"category": "Категория",
"size": "размер в KB",
"updated": "2026-07-26"
}
}

Как добавить своё приложение
Создай папку с именем приложения

Внутри папки создай index.html (это главный файл)

Добавь любые другие файлы (css, js, изображения)

Заархивируй папку в ZIP (имя папки = имя ZIP)

Положи ZIP в папку apps/

Добавь запись в info.json

Сделай коммит и пуш

Правила создания приложений
Обязательные требования:

В приложении должна быть кнопка выхода

Кнопка выхода вызывает window.parent.postMessage({ type: 'goose_close' }, '*')

Приложение не должно мешать работе других приложений

Приложение должно использовать API ядра для доступа к данным

Запрещено:

Мошенничество и обман пользователей

Кража или подмена ключей пользователей

Вредоносный код, портящий систему

Сбор личных данных без явного согласия

Подделка подписей или транзакций

Нарушение работы Гусиного Ядра

Рекомендации:

Используй тёмную тему оформления

Добавляй иконку для приложения

Указывай версию приложения

Описывай изменения в комментариях

API ядра
Базовый URL: http://127.0.0.1:8080/api

Работа с данными
GET /data/main - получить все публичные данные
GET /data/main/name - получить имя пользователя
GET /data/main/id - получить ID
GET /data/main/pub_key - получить публичный ключ
GET /data/main/pub_sig - получить подпись паспорта

POST /data/main/name - изменить имя (тело: {"value": "новое имя"})
POST /data/main/pub_key - изменить публичный ключ (только через шифровальщик)
POST /data/main/pub_sig - изменить подпись (только через шифровальщик)

GET /data/app/{имя} - получить данные конкретного приложения
POST /data/app/{имя}/{ключ} - сохранить данные приложения

GET /data/priv?auth=password123 - получить приватные данные
POST /data/priv/{ключ}?auth=password123 - сохранить приватные данные

Криптография
GET /crypto/pubkey - получить публичный ключ текущего пользователя
GET /crypto/generate - сгенерировать новые ключи

POST /crypto/sign - подписать данные
Тело: {"data": "текст", "use_stored": true}
Ответ: {"signature": "подпись"}

POST /crypto/verify - проверить подпись
Тело: {"data": "текст", "signature": "подпись", "pub_key": "публичный ключ"}
Ответ: {"valid": true/false}

POST /crypto/encrypt - зашифровать сообщение
Тело: {"message": "текст", "pub_key": "публичный ключ"}
Ответ: {"encrypted": "зашифрованный текст"}

POST /crypto/decrypt - расшифровать сообщение
Тело: {"encrypted": "текст", "use_stored": true}
Ответ: {"decrypted": "расшифрованный текст"}

Паспорт
GET /passport - получить паспорт текущего пользователя
GET /passport?resign=true - переподписать паспорт

Приложения
GET /apps/list - получить список установленных приложений
POST /upload?name=имя.zip - загрузить новое приложение (тело: ZIP-файл)

Как протестировать приложение локально
Запусти Гусиное Ядро (go run main.go)

Открой http://127.0.0.1:8080

Нажми на своё приложение в магазине

Проверь, что всё работает
